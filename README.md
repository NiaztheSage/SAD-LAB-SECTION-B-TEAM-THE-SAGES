# National & International Organ Donation and Transplant Coordination Network

A web-based system that connects hospitals, donors, patients and doctors, so organ donation and transplants can be coordinated in one place.

> **Important:** This system supports coordination and clinical decision-making only. It does **not** decide brain death, donor eligibility, transplant eligibility or final organ allocation. Doctors and authorities make those decisions.

---

## What it does

- Registers donors (living and deceased-donor intention) and recipients
- Connects hospitals in Bangladesh with selected hospitals abroad
- Helps doctors review compatibility between donors and patients
- Coordinates deceased donor cases
- Supports paired kidney exchange (two incompatible pairs swap donors)
- Handles patient referrals between hospitals
- Stores medical reports and case history
- Tracks organ transport and transplant records
- Records post-transplant follow-up
- Sends alerts and reminders
- Shows statistics on dashboards
- Keeps audit logs and protects private data

## User roles

| Role | What they do |
|---|---|
| Super Admin | Runs the platform, verifies hospitals, manages users |
| Hospital Admin | Manages a hospital's staff, cases and reports |
| Medical Professional | Reviews cases and matches, records transplants and follow-ups |
| Donor | Registers, uploads documents, tracks verification status |
| Recipient | Registers, uploads reports, requests referrals, tracks case |
